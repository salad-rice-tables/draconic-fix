## Findings 2026-11-16 (template/base-library scan)
* The CoA addons are built on **Ascension's own SharedXML** (a 3.3.5 backport of retail SharedXML, already extracted: `data/coa_client/patch-B/Interface/SharedXML`, 136 files, plus FrameXML 378 files). Templates such as StandardButtonTemplate, RaisedPortraitFrameTemplate, NineSlicePanelTemplate2, ScrollListTemplate, SpellIconTemplate, BorderIconTemplate are defined there (`SharedPanelTemplates.xml`, `SharedTemplates.xml`, `Scroll/ScrollList.xml`), NOT in Midnight and not in the CoA addons themselves.
* Many names collide with Midnight globals (Mixin, CreateFromMixins, ScrollList ...), so loading Ascension's SharedXML as is would overwrite Midnight's. Plan: load it into a private namespace (rename prefix `CoA_` for templates, run the CoA lua with a custom environment `setfenv`-style table that falls back to _G).
* Midnight already has a native **Wardrobe / transmog** (Collections > Appearances): do NOT port CoA's Wardrobe; only the Vanity store tab (Book of Descension, Book of Artisans, Travel Permit...) is CoA specific.
* Engine C APIs to implement in Lua: see the lists above (C_CharacterAdvancement ~60 fns, C_BuildEditor, C_ClassInfo, C_Logger, C_Config, ...). Data source on our side: `characters.coa_talent_ranks` + `data/coa_dbc/CA_*.dbc` (already extracted) + the server addon messages.
* mpyq installed (pip) for `tools/coa_mpq_scan.py` (lists every MPQ, `find <template>` shows which archive defines it; Ascension base UI lives in patch-B.MPQ).
